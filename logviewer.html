왼쪽에서 트레이스를 선택하세요

검색 · 그룹 정규식 도움말

두 칸이 하는 일

검색 (앞칸)셀 줄을 고릅니다. 글자 그대로 찾고, / 로 시작하면 정규식. 비우면 모든 줄
그룹 정규식 (뒷칸)고른 줄을 무엇으로 묶을지. 비우면 숫자·UUID·IP·이메일을 {N} 같은 자리표시자로 바꿔 자동으로 묶습니다

두 칸은 집계 버튼(또는 Enter)을 누를 때 함께 적용됩니다 — 검색으로 줄을 고른 다음, 그 줄들만 그룹 정규식으로 묶어 셉니다.

캡처그룹 ( ) 이 있으면그 값이 그룹 키가 됩니다
캡처그룹이 없으면매칭된 문자열 전체가 키가 됩니다
그룹이 여러 개면 / 로 이어 붙여 하나의 키로 씁니다
매칭되지 않는 줄은집계에서 빠집니다 — 필요한 줄만 골라 세는 데 쓰세요
대소문자를 무시하려면/패턴/i 처럼 슬래시로 감싸고 뒤에 i

검사 대상은 wrapper 접두어(INFO | jvm 1 | 날짜 |)와 James 헤더(레벨·스레드·로거)를 떼어낸 메시지 본문입니다. 스택트레이스 줄도 함께 검사합니다. 문법은 자바스크립트 정규식입니다.

예제 — 클릭하면 두 칸에 함께 채워집니다

무엇을 세나검색그룹 정규식
메일박스 파일 없음 오류를 사용자별로 no file for message namemaildir/[^/]+/([^/]+)/
같은 오류를 사용자 / 폴더별로 no file for message namemaildir/[^/]+/([^/]+)/(\.?[^ ]+)$
같은 오류를 도메인 / 사용자별로 no file for message namemaildir/([^/]+)/([^/]+)/
한 사람만(hoonkim) 폴더별로 no file for message namemaildir/[^/]+/hoonkim/(\.?[^ ]+)$
예외 종류별 발생 건수 ^([\w.$]+(?:Exception|Error)):
예외가 터진 소스 위치별 at ([\w.$]+\.[\w$]+)\([\w$]+\.java:\d+\)
응답코드별 (SMTP·POP3·IMAP) ^\[(\d{3})[ \]]
메일 주소의 도메인별 @([\w-]+\.[\w.-]+)
maildir 경로가 나오는 모든 줄을 사용자별로 maildir/[^/]+/([^/]+)/

주의 — 집계는 줄 단위라, 서로 다른 줄에 있는 값은 한 번에 묶을 수 없습니다. IO file not found from 은 WARN 줄에 있고 maildir/… 경로는 바로 다음 예외 줄에 있어서, 그 문구로 검색한 뒤 경로로 묶으면 0건이 됩니다. 이때는 같은 줄에 있는 no file for message name 으로 검색하세요.

반대로 검색을 비우고 경로로만 묶으면 오류가 아닌 줄(메일 삭제·저장 로그 등)까지 세므로, 건수가 실제 오류보다 훨씬 커집니다.

자주 쓰는 조각

[^/]+/ 가 아닌 글자 1개 이상 — 경로에서 한 칸만 집을 때
\S+ · .+공백 아닌 글자 · 아무 글자 (줄 끝까지)
\d+ · \w+숫자 · 영문/숫자/_
^ · $메시지 본문의 시작 · 끝
(?: )묶기만 하고 키에는 넣지 않는 그룹
a|ba 또는 b
\.점 글자 그 자체 (. 만 쓰면 “아무 글자”라는 뜻)

검색칸에서도 쓸 수 있어요

이 검색 칸과 트레이스·에러 탭의 검색칸 모두 / 로 시작하면 정규식으로 걸러냅니다. / 없이 쓰면 지금까지처럼 글자 그대로 찾습니다.

hoonkim그 글자가 들어간 행 (지금까지와 같음)
/^hoonkim$/정확히 hoonkim 인 행만
/hoonkim|jclee/둘 중 하나가 들어간 행
/Trash/i대소문자 무시

정규식이 아직 완성되지 않았으면 칸 테두리가 빨개지고, 그동안은 걸러내지 않고 전부 보여줍니다. 트레이스 탭 검색은 대소문자를 가리지 않습니다.

쓰는 순서

검색과 그룹 정규식을 채우고 Enter 또는 집계 버튼 → 건수 많은 순으로 정렬됩니다. 행을 클릭하면 그 줄이 있는 트레이스로 이동합니다.

집계에 쓰인 줄 수는 오른쪽 힌트에 검색 N줄 · 집계 N줄 · 전체 N줄 로 표시됩니다.
